IPASTRONG site build
======================
Files:
- index.html : new fast animated catalog storefront
- catalog.json : lightweight catalog generated from the uploaded source
- ipastrong-source.json : original source copy used to generate the catalog

Apps included in catalog.json: 844

The site does NOT install IPAs. Every "تنزيل التطبيق" button opens:
https://t.me/ipastrong

Upload index.html and catalog.json to the same GitHub Pages folder.
Do not upload ipastrong-source.json unless you want to keep a backup.
