ربط الكتابة

اربط مستودعك بـGitHub

التطبيقات تظهر بدون ربط. حتى تحفظ تغييراتك، استخدم رمز وصول خاص بمستودع ipastrong.

الربط فعّال في هذه الصفحة. الرمز لا يُحفظ بعد تحديث الصفحة أو إغلاقها.

  1. افتح صفحة إنشاء الرمز من الزر أدناه.
  2. في Repository access اختار Only select repositories ثم ipastrong.
  3. ضمن Repository permissions خلي Actions → Read and write. باقي الصلاحيات تبقى مثل ما هي.
  4. اضغط Generate token وانسخ الرمز لهنا.
إنشاء رمز الربط على GitHub ↗

الرمز يبقى بذاكرة الصفحة، ويُرسل إلى api.github.com فقط. ما ينحفظ بالمستودع ولا ينرسل إلى سيرفر آخر. بعد تحديث الصفحة تحتاج تلصقه مجددًا.
