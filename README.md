# ipastrong Website
واجهة متجر IPA تعتمد مباشرة على `ipastrong.json`.
- ارفع `index.html` و`offers.html` إلى جذر المستودع.
- GitHub Pages: `main` + `/(root)`.
- قناة Telegram: https://t.me/ipastrong


## المصادر المضافة
تمت إضافة دعم تحميل ودمج عدة مصادر JSON/AltStore مباشرة من الروابط الموجودة داخل `index.html`. بعض المصادر قد لا تسمح بالتحميل من المتصفح بسبب CORS أو اختلاف صيغة البيانات، لذلك تظهر التطبيقات من المصادر التي تسمح بالوصول فقط.
