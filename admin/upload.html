١. إعداد رمز الرفع — أول مرة
  1. افتح إعدادات مشروعك من الزر أدناه.
  2. من Settings → Repository افتح Deploy tokens ثم Add token.
  3. سمّه IPA Strong Upload وفعّل read_package_registry وwrite_package_registry فقط، وحدّد تاريخ انتهاء مناسب.
  4. اضغط Create deploy token وانسخ قيمة Token للخانة أدناه. اسم المستخدم ما نحتاجه.
فتح إعدادات مشروع GitLab ↗

هذا رمز GitLab خاص بالرفع؛ يختلف عن رمز GitHub مال لوحة التعديل. ما تدزّه بالمحادثة.

يبقى بذاكرة الصفحة ويُرسل إلى GitLab فقط، وما ينحفظ بعد تحديث الصفحة.

الاسم بالإنكليزي، بدون فراغات. محتوى ملفك ما يتغيّر.

خلي Safari مفتوح والشاشة شغّالة لحد يكمل الرفع. إذا انقطع، الرفع ما يستأنف تلقائيًا.

حتى يفتح الرابط عند المشتركين: من إعدادات المشروع Settings → General → Visibility, project features, permissions تأكد أن Package registry مفعّل، وفعّل Allow anyone to pull from package registry إذا موجود. أو اجعل المشروع Public إذا مناسب إلك. بعدها ارجع واضغط فحص الرابط؛ ما يحتاج تعيد رفع الملف.
